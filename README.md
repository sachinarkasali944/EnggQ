# EnggQ

> Android debug-build artifact and GitHub Pages configuration.

## Repository contents

- [app-debug.apk](./app-debug.apk): the committed Android debug APK.
- [_config.yml](./_config.yml): GitHub Pages/Jekyll configuration.

## Current scope

This repository contains a build artifact rather than an Android source project. Gradle files and application source are not included, so a fresh app build cannot be reproduced from this checkout.

The APK is for an Android device or emulator; it is not an iOS app and does not open in Xcode. The previous generic GitHub Pages template has been replaced with this inventory of the committed files.
